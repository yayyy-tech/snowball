⚙️ BACKEND LOGIC
1.	Profile Processing API (/api/processProfile)
•	Input: User profile JSON
•	Output: JSON roadmap containing:
•	Asset allocation
•	Recommended funds/bonds/ETFs with metadata
•	Logic:
•	If age < 30 → higher equity allocation (70%)
•	If moderate risk → equity 50%, hybrid 20%, debt 25%, gold 5%
•	If conservative → equity 30%, debt 60%, gold 10%
•	Picks relevant funds from mock datasets (or API if available).
2.	Recommendations API (/api/recommendations)
•	Fetch:
•	Mutual funds: AMFI or static curated JSON
•	Corporate bonds: scrape Wint Wealth’s active listings (fields: name, coupon, maturity, rating)
•	Gold ETFs: static JSON (HDFC, Nippon, SBI, ICICI)
•	Returns curated list per user profile.
3.	Report Generation API (/api/exportReport)
•	Converts roadmap to downloadable PDF using pdfkit.
•	Includes logo, allocation chart, recommendations, disclaimer.
